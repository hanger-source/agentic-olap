# 来源工作进程

构件通过 `ApplicationMainKt --mode worker` 运行，由 Kotlin 主服务创建、借用、取消和关闭，实际进程边界使用 `agentic-olap-runtime/v6` 的正式 Protobuf 消息。来源返回后，工作进程先交出与本次请求关联的读取事实，再继续核心求值及最终结果交付。

主服务持有 H2、语义定义、采用、发布、查询版本、使用记录与结果授权。工作进程不拥有元数据库、HTTP 服务或 REPL 编译器。

每个工作角色按本次获授权的输入装载精确连接器，完成调查、编译、候选值或查询执行。每次请求有身份、期限、取消与部署预算；只有实际来源工作才取得本次精确来源需要的环境。通信消息不复制内部计算规则。

工作处理器负责语义、规划、类型、数量、来源保证与结果正确性。主服务拥有进程句柄、精确来源配置、借用和终止；结果文件与运行记录由主服务在本地完成，不经过监督者保存确认协议。

业务使用统一 MCP 服务。该构件与内部通信不是另一条免治理产品流程；部署与使用入口见[服务说明](../../../../skills/agentic-olap/references/server.md)，职责见[架构](../../../../docs/architecture.md)。
