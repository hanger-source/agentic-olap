# JVM 应用

Kotlin 应用构件通过 `ApplicationMainKt --mode metadata|worker` 运行。进程由 Go 服务启动和监督，应用内部使用 `project/protocol/runtime.proto` 生成的双向消息通信。

元数据模式唯一持有 H2、语义定义、采用、发布、查询版本、使用记录与结果授权。操作描述、输入合同和处理入口来自同一注册项，按实际请求主体核对能力及资源。技术调查和计算通过工作端口交给 Go，元数据进程不启动子 JVM，不持有业务来源凭据。

工作模式按本次获授权的输入装载精确连接器，完成调查、编译、候选值和查询执行。每次请求有身份、期限、取消与资源预算；只有实际来源工作才取得本次精确来源需要的环境。公共 Query 继续使用 JSON，通信消息不复制内部计算模型。

Go 负责在途准入、工作池、取消、终止及关闭。Kotlin 负责语义、规划、类型、数量、来源保证与结果正确性。结果字节由 Go 交付或保存，Kotlin 在核对封存回执后提交结果 manifest 和交付状态。

业务使用统一 MCP 服务。该构件与内部通信不是另一条免治理产品流程；部署与使用入口见[服务说明](../../../../skills/agentic-olap/references/server.md)，职责见[架构](../../../../docs/architecture.md)。
